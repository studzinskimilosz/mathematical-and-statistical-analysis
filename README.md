### Mathematical and statistical analysis of the shares of PGE SA
> 🚧 **STATUS: IN PROGRESS!** 🚧

## 📝 Project Description
This project aims to perform a basic and advanced mathematical and statistical analysis of the stock market quotes of **PGE SA** (Polska Grupa Energetyczna). The analysis covers historical trends, volatility, return distributions, time series analysis, and other key market indicators.

## 🔄 Project Pipeline
The analysis follows a structured data pipeline to ensure reproducibility:
1. **Data Ingestion:** Fetching historical PGE SA stock data (e.g., using `yfinance`, Stooq, or GPW APIs).
2. **Data Preprocessing:** Cleaning missing values, handling market holidays, and calculating daily/log returns.
3. **Exploratory Data Analysis (EDA):** Visualizing price movements, moving averages, and trading volume trends.
4. **Statistical Analysis & Modeling:** Applying statistical tests (e.g., normality tests) and volatility modeling (e.g., GARCH) based on the project's literature.
5. **Reporting:** Consolidating insights, charts, and metrics into Jupyter Notebook summaries.

## 🛠️ Technologies & Tools
- **Programming Languages:** Python 
- **Libraries:** Pandas, NumPy, SciPy, Matplotlib, Seaborn
- **Environment:** Jupyter Notebook
